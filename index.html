Пароль можно изменить только на официальном Discord-сервере команды MBM.

Инструкция

  1. Зайдите на сервер.
  2. Найдите текстовой чат «тикет».
  3. Создайте тикет.
  4. Опишите проблему: «забыли пароль».
  5. Ожидайте ответа Администратора.

Настройка Облачной БД Supabase

Введите URL и Анон-ключ вашего проекта Supabase. Данные будут автоматически синхронизироваться с таблицей site_config.

SQL Таблица в Supabase: 
CREATE TABLE site_config (
  id TEXT PRIMARY KEY,
  data JSONB NOT NULL,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

Диагностика MBM / Supabase

Проверка показывает, доступен ли Supabase без VPN, восстанавливается ли сессия и загружается ли профиль. Пароль и anon key сюда не выводятся.
